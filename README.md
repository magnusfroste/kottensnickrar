# Kotten snickrar – såga rätt längd

Statisk skolapp (HTML/CSS/JS, inga beroenden) för åk 1–3: mät öppningen med linjalen och
välj var brädan ska sågas så att hyllan passar. Tränar Lgr22 MA.1-3.3.3 (mätning av längd)
och MA.1-3.1.8 (rimlighetsbedömning).

- `public/` – appen (serveras som den är)
- `kit.py` – ritar ikoner, favicon, og-bild, manifest, robots, sitemap
- `verify.mjs` – kontrollerar uppgiftsgeneratorn (`node verify.mjs`)
- `deploy/nginx.conf` – serverkonfig

Publicerad på https://kottensnickrar.shipholm.dev
